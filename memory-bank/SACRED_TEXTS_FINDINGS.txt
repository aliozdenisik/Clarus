FORMAT SPECIFICATIONS
================================================================================

JSON Format (Easiest to parse)
──────────────────────────────
- Pseudepigrapha OAP: Flat JSON with metadata
- KJA Apocrypha: Verse-indexed structure
- DharmicData: Chapter/verse organization
- BiblicalDSS: Hierarchical text structure

XML Formats
────────────
- OSIS (Open Scripture Information Standard)
  Used by: OSIS Bibles, 1 Enoch
  Advantage: Bible-standard format, widely supported
  
- EpiDoc (TEI-compliant)
  Used by: Church Fathers CSEL
  Advantage: Scholarly apparatus, critical editions
  
- Text-Fabric
  Used by: Dead Sea Scrolls
  Advantage: Rich linguistic annotations, Python ecosystem

HTML (Web-based)
─────────────────
- Early Christian Writings: Browsable online
- Sacred Texts Archive: Comprehensive but requires scraping
- New Advent: Church Fathers collection
