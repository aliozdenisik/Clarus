## Reporting a Vulnerability

We take the security of Clarus seriously. If you have discovered a security vulnerability, please report it to us immediately.

**DO NOT** open a public issue on GitHub for security vulnerabilities.

### How to Report

Please email us at [security@yourdomain.com] with a description of the vulnerability and steps to reproduce it. We will acknowledge your report within 48 hours and provide an estimated timeline for a fix.

### Response Process

1. **Triage**: We will investigate the report to confirm the vulnerability.
2. **Fix**: We will work on a patch to resolve the issue.
3. **Release**: We will release a security update and notify users.
4. **Disclosure**: Once the fix is released, we will publicly disclose the vulnerability.

Thank you for helping keep Clarus secure!
