## Issue Priorities

- **High:** Affects core functionality or user experience significantly
- **Medium:** Important improvements but not blocking
- **Low:** Minor inconsistencies or nice-to-have improvements

## Issue Status

- **Open:** Not yet started
- **In Progress:** Currently being worked on
- **Resolved:** Fixed and merged
- **Closed:** Won't fix or duplicate

## How to Add a New Issue

1. Create a new file: `XXX-descriptive-name.md` (use next available number)
2. Use the template below
3. Add an entry to this README table
4. Update the status as work progresses
